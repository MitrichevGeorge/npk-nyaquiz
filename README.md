# НПК «Инженеры будущего» — интерактивный квиз

**nyaquiz** — это веб-платформа для проведения интерактивных квизов в реальном времени, разработанная в рамках научно-практической конференции **«Инженеры будущего»** (НПК).

> Наш проект — это интерактивный квиз, который делает процесс проверки знаний и обучения увлекательным: ведущий запускает викторину, а участники отвечают со своих устройств в режиме реального времени.

---

## Что такое квиз?

**Квиз** (от англ. *quiz*) — это интерактивная игра-викторина, в которой участники отвечают на вопросы, а система автоматически проверяет ответы, начисляет баллы и подводит итоги.

Ключевые особенности квиза как формата:

- **Вопросы и варианты ответов** — ведущий заранее готовит вопросы, участники выбирают один или несколько вариантов ответа.
- **Реальное время** — все участники видят вопросы одновременно и отвечают в отведённый промежуток времени.
- **Автоматическая проверка** — система мгновенно определяет правильность ответов, не требуя ручной проверки.
- **Соревновательность** — баллы и рейтинг участников обновляются в реальном времени, что делает игру азартной и мотивирующей.
- **Мгновенная обратная связь** — после каждого вопроса ведущий и участники видят правильный ответ и распределение ответов.

Именно такой формат реализован в проекте **nyaquiz**: он превращает обычную проверку знаний в живое, интерактивное мероприятие.

---

## О проекте

**nyaquiz** — полноценная клиент-серверная платформа для живых квизов:

- Ведущий создаёт квиз, запускает сессию (комнату) и управляет её этапами: **лобби → вопрос → результаты**.
- Участники присоединяются к комнате по **коду** или **QR-коду** и отвечают со своих смартфонов, планшетов или компьютеров.
- На большом экране (или через видеотрансляцию) отображается **режим трансляции** с вопросом, таймером, результатами и рейтингом.

Платформа подходит для уроков, конференций, командных мероприятий и любых сценариев, где нужна живая проверка знаний.

## Возможности

### Для ведущего
- Создание, редактирование, удаление и восстановление квизов.
- **Версионирование** квизов с возможностью отката к предыдущей версии.
- Запуск комнат с уникальным кодом и QR-кодом для входа.
- Управление этапами сессии (лобби, вопрос, показ результатов, итоговый рейтинг).
- Настраиваемая система начисления баллов:
  - «всё или ничего»;
  - «за каждый вариант»;
  - «по числу верных ответов»;
  - произвольная карта баллов.
- **Бонус за скорость** ответа с настраиваемыми коэффициентами.
- Реакции участников (эмодзи) в реальном времени.
- Экспорт: **QR-код**, **раздаточный PDF** с кодом входа, выгрузка результатов.

### Для участников
- Вход в комнату по коду или QR без регистрации (только никнейм).
- Ответы на вопросы в реальном времени.
- Мгновенная обратная связь и обновление рейтинга.

### Общие
- **Реальное время** через Server-Sent Events (SSE) и внутренний pub/sub брокер.
- Мультиязычность интерфейса (русский / английский).
- Поддержка формул (**KaTeX**), диаграмм (**Mermaid**) и разметки (**Markdown**) в вопросах.
- **AI-помощник** (опционально): генерация и правка вопросов, распознавание формул с фотографий (LaTeX OCR) и транскрибация аудио (Whisper).
- Безопасность: CSRF-защита, безопасные сессии, ограничение частоты запросов, хеширование паролей, шифрование секретов.

### Аккаунты и безопасность
- Регистрация, вход, восстановление пароля, удаление аккаунта.
- Двухфакторная аутентификация: **TOTP**, **код по email**, резервные коды.
- **QR-вход** на устройстве ведущего.
- Защита от перебора пароля (блокировка учётной записи).

### Административная панель
- Отдельный сервис, доступный только на loopback-интерфейсе (`127.0.0.1`).
- Вход с обязательной двухфакторной аутентификацией.
- Статистика платформы и журнал аудита действий администраторов.

## Быстрый старт

### Требования
- Docker и Docker Compose
- (для фронтенда) Node.js и npm

### Запуск в продакшен-режиме

1. Скопируйте `.env` и заполните секреты:
   ```bash
   cp .env .env.local
   ```
   Обязательно смените `POSTGRES_PASSWORD`, `ENCRYPTION_KEY` (32-байтовый ключ в base64) и `AI_API_KEY` при использовании ИИ.

2. Соберите и запустите сервисы:
   ```bash
   make up
   ```

3. Платформа будет доступна на `http://localhost`, бэкенд отвечает на `/health`.

### Режим разработки

```bash
make dev        # запуск с dev-оверлеем
make build-front # сборка фронтенда
```

### Полезные команды

| Команда              | Назначение                                              |
|----------------------|---------------------------------------------------------|
| `make up` / `make down` | Запуск / остановка всех сервисов                    |
| `make dev`           | Запуск в режиме разработки                              |
| `make build-front`   | Сборка фронтенда (esbuild)                              |
| `make test`          | Запуск тестов (pytest)                                  |
| `make lint`          | Проверка кода (ruff)                                    |
| `make typecheck`     | Проверка типов (mypy)                                   |
| `make check-admin-bind` | Проверка, что админ-панель доступна только на loopback |
| `make loadtest`      | Нагрузочное тестирование (k6)                           |

## Как провести квиз

1. **Зарегистрируйтесь** и войдите в аккаунт ведущего.
2. **Создайте квиз** в личном кабинете и добавьте вопросы.
3. **Запустите комнату** — система сгенерирует код входа и QR-код.
4. **Пригласите участников** — они сканируют QR или вводят код и указывают никнейм.
5. **Управляйте этапами**: лобби → вопрос → результаты → финальный рейтинг.
6. **Транслируйте** ход игры на большом экране через режим трансляции.
